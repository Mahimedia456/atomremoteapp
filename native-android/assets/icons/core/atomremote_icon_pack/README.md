# AtomRemoteBackend Icon Pack

Original icon set matching the cyan/black UI direction from the approved mockup.

Included:
- SVG source icons
- 256x256 PNG renditions (when runtime conversion is available)
- manifest.json with colors and Android sizing guidance

Core UI:
settings, wifi, monitor, SSD, codec, battery, waveform, focus, zebra,
false color, LUT, frame guide, grid, zoom, safe area, record, stop,
play, pause, connected, signal bars, timecode, HDMI input, remote mark.

Note:
`remote_mark` is an original geometric app mark, not the official ATOMOS trademark/logo.
